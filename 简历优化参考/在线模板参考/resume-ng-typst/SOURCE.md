## Layout references

- Dense but readable one-page information hierarchy with a centered identity header.
- Reusable section, education, work, and project primitives keep dates and roles aligned.
- Fine rules and restrained spacing separate sections without adding card-like decoration.
- Local files retain the minimal Typst example structure: `template/main.typ` and `lib/lib.typ`.

The example content is kept only as a layout reference and is not used as content for the personal resume.
